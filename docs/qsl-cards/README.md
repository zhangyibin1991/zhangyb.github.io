# QSL卡片展示系统使用说明

## 概述

这是一个动态的QSL卡片展示系统，可以按年份组织和展示您的QSL卡片。系统支持自动扫描目录中的图片文件，并提供丰富的筛选和搜索功能。

## 文件结构

```
docs/
├── qsl-cards.html          # 主页面文件
└── qsl-cards/
    ├── generate_index.py   # 索引生成脚本
    ├── index.json          # 图片索引文件（自动生成）
    ├── 2025/               # 按年份组织的图片目录
    │   ├── M5BVP89TO9_5a7v823uoye.jpg
    │   ├── M5CNWPME3P_edomgzckez.jpg
    │   └── ... (更多图片)
    └── README.md           # 本说明文件
```

## 使用方法

### 1. 添加新的QSL卡片

1. 将新的QSL卡片图片放入对应的年份目录中
   - 例如：2026年的卡片放入 `qsl-cards/2026/` 目录
   - 文件名建议格式：`呼号_随机码.jpg`（如：`BG5FUC_abc123.jpg`）

2. 重新生成索引文件：
   ```bash
   cd docs/qsl-cards
   python generate_index.py
   ```

3. 刷新浏览器页面即可看到新添加的卡片

### 2. 索引生成脚本说明

`generate_index.py` 脚本会：
- 扫描所有年份目录（如2025, 2026等）
- 识别图片文件（.jpg, .jpeg, .png, .gif）
- 提取呼号（从文件名的第一部分）
- 生成 `index.json` 索引文件

### 3. 页面功能特性

#### 动态加载
- 页面启动时自动加载 `index.json`
- 支持缓存清除，确保显示最新数据
- 内置备用数据，方便本地测试

#### 按年份展示
- 自动按年份分组显示
- 每个年份有独立的标题和计数
- 年份按倒序排列（最新在前）

#### 筛选功能
- **年份筛选**：只显示特定年份的卡片
- **波段筛选**：20m, 40m, 80m 等
- **模式筛选**：SSB, CW, FM, AM 等

#### 视觉效果
- 平滑的加载动画
- 悬停效果和过渡动画
- 响应式设计，支持移动设备
- 图片加载状态显示

#### 刷新功能
- 页面顶部提供"刷新数据"按钮
- 点击后重新加载 `index.json`
- 自动更新统计信息和卡片展示

## 技术实现

### 前端技术
- **HTML5**：语义化结构
- **CSS3**：现代样式，CSS变量，响应式设计
- **JavaScript**：ES6+，异步加载，动态渲染
- **GSAP**：高级动画效果

### 数据流程
1. 浏览器加载 `qsl-cards.html`
2. JavaScript 尝试加载 `index.json`
3. 如果失败，使用内联示例数据
4. 解析数据并生成统计信息
5. 按年份分组渲染卡片
6. 应用动画和交互效果

### 图片处理
- 图片路径：`qsl-cards/{年份}/{文件名}`
- 加载状态：显示"加载中..."提示
- 错误处理：显示"图片加载失败"
- 自适应：图片自动适应容器宽度

## 部署说明

### GitHub Pages 部署
1. 确保所有文件推送到GitHub仓库
2. 在仓库设置中启用GitHub Pages
3. 访问 `https://yourusername.github.io/qsl-cards.html`

### 本地测试
1. 启动HTTP服务器：
   ```bash
   python -m http.server 8000 --directory docs
   ```
2. 访问 `http://localhost:8000/qsl-cards.html`

## 故障排除

### 问题：页面显示空白或错误
**解决方案**：
1. 检查浏览器控制台错误信息
2. 确认 `index.json` 文件存在且格式正确
3. 尝试手动刷新页面

### 问题：图片无法显示
**解决方案**：
1. 检查图片路径是否正确
2. 确认图片文件格式支持
3. 检查浏览器是否阻止了图片加载

### 问题：筛选功能不工作
**解决方案**：
1. 检查JavaScript是否有错误
2. 确认数据格式正确
3. 尝试清除浏览器缓存

## 自定义配置

### 修改颜色主题
在HTML文件的CSS部分修改变量：
```css
:root {
    --accent-color: #4a90e2;  /* 主题色 */
    --primary-color: #222;     /* 主要文字颜色 */
}
```

### 修改筛选条件
在JavaScript的 `initFilters()` 函数中添加或修改筛选按钮：
```javascript
const additionalFilters = ['15m', '10m', 'AM'];
```

### 修改动画效果
在 `initAnimations()` 和 `initCardAnimations()` 函数中调整GSAP参数。
